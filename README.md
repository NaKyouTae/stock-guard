# stock-guard

> 여러 증권 계좌를 한곳에 모아 관리하고, 투자 고수의 포트폴리오와 비교하며, AI가 다음 투자를 추천하고 하락장에서 자산을 지켜주는 주식 관리 서비스

단발성 트레이딩 도구가 아니라, **평생 곁에서 자산을 지키고 함께 키워가는 투자 파트너**를 지향합니다. 국내 주식과 미국 주식을 모두 다룹니다.

## 핵심 기능

- **📊 통합 계좌 관리** — 본인 및 가족(자녀·배우자 등) 여러 계좌를 연결해 자산 현황을 한눈에 조회
- **👥 고수 포트폴리오 비교** — 유명 투자자의 포트폴리오를 가져와 내 포트폴리오와 비교·벤치마킹
- **🤖 AI 투자 추천** — 보유 현황과 시장을 분석해 다음에 살 종목을 AI가 추천
- **🛡️ 하방 보호(Guard)** — 하락장에서 리스크를 감지하고 자산을 지키는 방어 전략 제공
- **💱 거래 & 자동매매** — 앱 내 직접 거래, 나아가 전략 기반 자동매매
- **📈 포트폴리오 분석** — 수익률·리스크·자산 배분 분석

## 아키텍처

```
[Next.js 프론트] ──BFF/프록시──> [NestJS 백엔드] ──Prisma──> [MySQL]
      │                                                        │
   웹 우선 → 추후 웹뷰(모바일)                          Prisma Migrate (형상관리)
```

## 기술 스택

### Frontend — Next.js

| 구분 | 선택 | 비고 |
|------|------|------|
| 프레임워크 | Next.js (App Router) + React 19 | 웹 우선, 추후 웹뷰 |
| 스타일 | Tailwind CSS v4 | 토스식 커스텀 디자인 시스템 |
| 애니메이션 | Motion (Framer Motion) | 전환/제스처/바텀시트 |
| 컴포넌트 | Radix UI (headless) + Vaul(바텀시트) | 룩은 직접 컨트롤 |
| 차트 | lightweight-charts | 주식 캔들/라인 |
| 폼/검증 | React Hook Form + Zod | 거래/계좌연결 |
| 서버 상태 | TanStack Query | 시세·잔고 폴링/캐싱 |
| 유틸 | es-toolkit, overlay-kit | 토스 오픈소스 |

### Backend — NestJS

| 구분 | 선택 |
|------|------|
| 프레임워크 | NestJS 11 |
| API | REST (BFF 프록시 패턴, httpOnly 쿠키 JWT) |
| 외부 연동 | 토스증권 오픈 API (시세/잔고/주문) |
| 인증 | JWT (토스 OAuth 연동 기반) |

### Database — MySQL + ORM + 형상관리

| 구분 | 선택 | 이유 |
|------|------|------|
| DB | MySQL 8 | — |
| ORM | Prisma 7 | 타입 안전, MySQL 완전 지원 |
| 형상관리 | Prisma Migrate | `schema.prisma` 단일 소스 → 마이그레이션 SQL을 git으로 이력 관리 |

## 프로젝트 구조 (pnpm 모노레포)

```
stock-guard/
├── app/          # Next.js — 사용자 웹 (추후 웹뷰)
├── server/       # NestJS — API
│   └── prisma/
│       ├── schema.prisma      # 스키마 단일 소스
│       └── migrations/        # 마이그레이션 이력 (형상관리)
├── admin/        # (선택) 관리자
└── pnpm-workspace.yaml
```

## 참고 (검토 필요 사항)

- **타인/가족 계좌 연결** — 토스증권 오픈 API 약관 및 자본시장법상 대리 조회·매매 제약 여부 확인 필요
- **유명인 포트폴리오** — 국내는 공시 의무가 거의 없어 정확한 실시간 데이터 확보가 제한적일 수 있음 (미국 13F 등 일부만 공개)
- **자동매매** — 증권 API의 주문 권한·인증·리스크 관리 요건 충족 필요
